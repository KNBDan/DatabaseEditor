Тестовое задание.
Десктоп приложение для создани, изменения и удаления таблиц в базе данных.
(Для запуска необходима Java 11 и выше, Postgres 12 и выше)
В jar есть все зависимости, для запуска подключене к инетрнету не требуется.

Ссылка на гит: https://github.com/KNBDan/DatabaseEditor
